# scanner-data

Generated data files for the TCG scanner app, published as GitHub Releases by the daily catalog pipeline.

- **Contents:** a card catalog (text only: names, set codes, numbers, Variants, cross-reference IDs) and daily USD market prices, plus a `manifest.json` describing them.
- **No card images** are published here.
- **Sources:** [Scryfall](https://scryfall.com) (Magic: The Gathering), [TCGdex](https://tcgdex.dev) (Pokémon) and [SWU-DB](https://swu-db.com) (Star Wars Unlimited). Card names and data belong to their respective rights holders; prices are TCGplayer market prices as provided by those sources.

This repository holds no code. Its releases are written by an automated workflow.
